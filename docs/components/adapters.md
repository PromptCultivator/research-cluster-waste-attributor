# Ingest Adapters

## 1. Overview

The `rcwa.adapters` package converts raw batch-scheduler accounting exports into canonical Polars DataFrames (`POLARS_CANONICAL_SCHEMA`):
1. [`rcwa/adapters/sacct.py`](../../rcwa/adapters/sacct.py): Slurm pipe-delimited `sacct` adapter (`parse_sacct`).
2. [`rcwa/adapters/swf.py`](../../rcwa/adapters/swf.py): Parallel Workloads Archive Standard Workload Format adapter (`parse_swf`, `parse_swf_with_pragmas`, `parse_swf_pragmas`).

---

## 2. Slurm `sacct` Adapter (`parse_sacct`)

### 2.1 Accepted Export Format

Accepts filesystem paths, UTF-8 text streams (`IO[str]`), or raw string payloads generated by:

```bash
sacct -a -P --units=M -S <start> -E <end> \
  --format=JobIDRaw,JobID,User,Account,Partition,QOS,JobName,Submit,Eligible,Start,End,Elapsed,State,ExitCode,\
ReqCPUS,AllocCPUS,ReqMem,MaxRSS,AveRSS,TotalCPU,CPUTimeRAW,ReqTRES,AllocTRES,NodeList,Comment,SubmitLine
```

### 2.2 Parsing, Validation, and Step Rollup

- **Binary / Corrupt Rejection**: Scans headers and string inputs for null bytes (`\x00`) or invalid UTF-8 decoding, raising `ValueError` on binary inputs. Empty or header-only files return `empty_canonical_df()`.
- **Header Resolution & Extra Columns**: Indexes fields dynamically by lowercased header name regardless of column order, handles trailing pipe delimiters (`|`), and emits a `UserWarning` for unrecognized extra columns (`KNOWN_SACCT_COLUMNS`) or headers lacking both `JobID` and `JobIDRaw`.
- **Step Hierarchy Aggregation**: Collects child step rows (`12345.batch`, `12345.0`, `12345.extern`) by parent `base_id` using `decompose_job_id`:
  $$\text{max\_rss\_mb} = \max_{\text{step} \in \text{steps},\ \text{MaxRSS} \neq \text{null}} \text{step.MaxRSS}$$
  $$\text{cpu\_time\_used\_s} = \sum_{\text{step} \in \text{steps} \setminus \{\text{extern}*\}} \text{step.TotalCPU}$$
  Steps named `extern` or prefixed with `extern` are excluded from `cpu_time_used_s` summation. When child step values are absent, the parser falls back to the parent allocation row counters.
- **Array & Heterogeneous Pack Jobs**: Elements such as `12345_0` and `12345+0` emit independent canonical rows with `parent_job_id = "12345"`.
- **Duration, Wait, and Resource Allocation**: Computes `run_s` from `Elapsed` (`parse_duration_int`), falling back to `(End - Start)` in seconds or `0`. Computes `wait_s = max(0, Start - Submit)` when both exist (else `0`). Resolves `alloc_cpus` and `req_cpus` with TRES fallback (`min 1`), `nodes` from `AllocTRES`/`ReqTRES`, GPU counts from `ReqTRES`/`AllocTRES`, and `req_mem_mb` via `parse_slurm_memory_mb`.
- **Hash Provenance**: Resolves `input_hash` from `Comment` (`RCWA_INPUT_HASH=<hex>`) first, falling back to `$RCWA_DIR/<job_id>.json` sidecars (`_read_sidecar_hashes`). Resolves `command_hash` from sidecar first, else SHA-256 of `SubmitLine`, else SHA-256 of `JobName`.

## 3. Standard Workload Format Adapter (`parse_swf`)

### 3.1 File Encoding & Pragmas

`parse_swf` and `parse_swf_with_pragmas` accept plaintext `.swf` files, gzip-compressed `.swf.gz` archives (`b"\x1f\x8b"` magic bytes), strings, and file streams. Comment lines starting with `;` are parsed by `parse_swf_pragmas` into metadata keys including:
- `UnixStartTime`: Base Unix epoch seconds added to relative SWF submit offsets.
- `MaxProcs`, `MaxNodes`, `Note`, `Version`, `Computer`, `Installation`.

### 3.2 Column Mapping and Scaling Rules

SWF lines with fewer than 11 whitespace-separated tokens are skipped. Missing numeric values encoded as `-1` translate carefully (`null` for metrics/metadata, `0` for durations, `alloc_cpus` fallback for `req_cpus`):

| SWF Col | Field | Canonical Transformation |
|---|---|---|
| 1 | Job Number | `job_id = str(int(float(val)))` |
| 2 | Submit Time | `submit_time = datetime(base_epoch + max(0, val), tz=UTC)` |
| 3 | Wait Time | `wait_s = max(0, int(float(val)))`; sets `start_time = null` when `-1` |
| 4 | Run Time | `run_s = max(0, int(float(val)))`; sets `end_time = null` when `-1` |
| 5 | Alloc Procs | `alloc_cpus = max(1, int(float(val)))` |
| 6 | Avg CPU Time | `cpu_time_used_s = val * alloc_cpus` (`null` if `< 0`) |
| 7 | Used Memory (KB/proc) | `max_rss_mb = int(round(val * alloc_cpus / 1024.0))` (`null` if `< 0`) |
| 8 | Req Procs | `req_cpus = val if val > 0 else alloc_cpus` |
| 10 | Req Memory (KB/proc) | `req_mem_mb = int(round(val * alloc_cpus / 1024.0))` (`null` if `< 0`) |
| 11 | Status | `map_swf_status(val)`: `1 -> COMPLETED`, `0 -> FAILED`, `5 -> CANCELLED`, else `OTHER` |
| 12 | User ID | `user = str(int(float(val)))` (`"unknown"` if absent) |
| 13 | Group ID | `account = str(val)` (`null` if `-1`) |
| 14 | Executable No | `command_hash = str(val)` (`null` if `-1`) |
| 15 / 16 | Queue No / Partition No | `partition` prefers Queue No (`!= -1`), falling back to Partition No (`!= -1`), else `null` |

Columns 9 (Requested Time), 17 (Preceding Job), and 18 (Think Time) are outside the 27-field canonical schema and omitted (`input_hash = null`, `source = "swf"`). Class 4 redundant recomputation is explicitly reported as `"not_available"` / `"not available"` on SWF traces and never estimated heuristically.
